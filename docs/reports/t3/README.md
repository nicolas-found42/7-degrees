# T3 reconciliation artifacts

`docs/reports/t3-reconciliation.md` (generated by `scripts/t3_reconcile.py` +
`scripts/t3_report.py`) is the **retained cross-source reconciliation report**
required by ticket T3 (#5): player universe, player-season-team membership, and
the franchise-alias crosswalk reconciled across S1/S2/S3, with every disagreement
listed for review.

Data artifacts referenced by the report (also retained in the repo, gitignored
data regenerated by the scripts):

- `t3/player-universe.csv` — canonical NBA/BAA player universe (5,106 players, including the S1-evidenced postseason-only supplement)
- `t3/franchise-crosswalk.csv` — all 1,818 S2 season-team rows resolved to one
  canonical franchise identity
- `t3/membership-mismatches.csv` — S2-only/S1-only membership differences with
  `diff_shape` classification
- `t3/unresolved-player-cases.csv` — every identity disagreement with class and
  both ids/names
